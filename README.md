# Международный фиксированный календарь — v1.6

## Что нового

- 🆕 **Турецкий, Польский, Японский, Корейский** — теперь 17 языков
- 🆕 **Экспорт в ICS** — скачать все праздники года для Google/Apple Calendar
- 🆕 **Разница между датами** — дни/недели/месяцы/годы + по МФК
- 🆕 **URL-роутинг** — `#/g/2026/10/8`, шарабельные ссылки
- 🆕 **Кнопка «Копировать» и «Поделиться»** (Web Share API)
- 🏗 **Модульная структура** — `js/`, `css/`, `locales/` вместо одного файла


## Развёртывание

- **Локально**: `python -m http.server` (ES-модули требуют HTTP)
- **GitHub Pages**: загрузить всё → Settings → Pages → main / root

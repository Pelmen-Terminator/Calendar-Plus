# Международный фиксированный календарь (МФК) — v1.2

Веб-приложение для перевода дат между **5 календарями** и **МФК**.

## Поддерживаемые календари

- 🌍 **Григорианский** (Gregorian)
- 🏛 **Юлианский** (Julian)
- 🀄 **Китайский солнечный** (24 сезона 节气 + 60-летний цикл 干支)
- ✡ **Еврейский** (Hebrew / לוח עברי)
- 📅 **МФК** (International Fixed Calendar — 13 × 28 + Високосный день)

## Возможности

- Перевод **между всеми календарями** через JDN (Julian Day Number)
- 35 международных праздников (включая День Победы Восток/Запад, День отца, День матери)
- **5 языков интерфейса** с выпадающим меню и флагами:
  - 🇷🇺 Русский
  - 🇬🇧 English
  - 🇧🇷 Português
  - 🇪🇸 Español
  - 🇨🇳 中文
- Автоопределение языка по `navigator.language`
- Светлая / тёмная тема
- Работает оффлайн (service worker)
- Настройки сохраняются в `localStorage`

## Использование

1. Выберите исходный календарь (Григорианский / Юлианский / Китайский / Еврейский)
2. Введите дату:
   - **Григорианский, Юлианский** — день / месяц / год
   - **Китайский** — номер сезона (1–24) / день (1–15) / год
   - **Еврейский** — месяц (Тишрей…Элул) / день / год
3. Нажмите **«Перевести»**
4. Результат покажет дату во **всех 4 календарях** + день недели в МФК

## Развёртывание на GitHub Pages

1. Загрузите все файлы в репозиторий.
2. **Settings → Pages → Source → Deploy from a branch**, выберите `main` и `/ (root)`.
3. Откройте `https://<username>.github.io/<repo>/`.

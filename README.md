# Международный фиксированный календарь (МФК) — v1.1

Веб-приложение для перевода дат между **григорианским**, **юлианским** и **Международным фиксированным календарём** (IFC).

## Возможности

- Перевод даты из григорианского или юлианского календаря в МФК и обратно
- Календарь на месяц и на весь год (13 месяцев по 28 дней + Високосный день)
- **35 международных праздников**, включая:
  - День Победы (Восток — 9 мая, Запад — 8 мая)
  - День отца, День матери, Мужской день
  - День памяти Холокоста, День океанов, День мигрантов и др.
- **5 языков интерфейса**: 🇷🇺 Русский, 🇬🇧 English, 🇧🇷 Português, 🇪🇸 Español, 🇨🇳 中文
- Переключение темы (светлая/тёмная)
- Сохранение настроек в `localStorage`
- Работает оффлайн (service worker)

## Языки

Кнопка переключения языка циклично меняет: **ru → en → pt → es → zh → ru**.
Автоопределение по `navigator.language` при первом запуске.

## Структура

- `index.html` — основное приложение
- `manifest.json` — PWA-манифест
- `favicon.svg`, `icon-192.png`, `icon-512.png` — иконки
- `sw.js` — service worker

## Развёртывание на GitHub Pages

1. Загрузите все файлы в репозиторий.
2. **Settings → Pages → Source → Deploy from a branch**, выберите `main` и `/ (root)`.
3. Откройте `https://<username>.github.io/<repo>/`.

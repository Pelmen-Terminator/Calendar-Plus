# Международный фиксированный календарь (МФК) — v1.4

Конвертер дат между **6 календарями** на **10 языках**.

## Календари (6)

- 🌍 Григорианский
- 🏛 Юлианский
- 🀄 Китайский солнечный (24 сезона)
- ✡ Еврейский
- 🕉 **Индуистский** (Викрам-самват)
- ☪ **Исламский** (Хиджра)

## Языки (10)

🇷🇺 RU · 🇬🇧 EN · 🇩🇪 **DE** · 🇫🇷 FR · 🇪🇸 ES · 🇧🇷 PT · 🇨🇳 ZH · 🇮🇳 **HI** · 🇮🇱 HE · 🇸🇦 AR

## Праздники (42)

- 38 международных
- ➕ Дивали, Холи (индуистские)
- ➕ Ураза-байрам, Курбан-байрам (исламские)

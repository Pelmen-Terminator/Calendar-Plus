# Международный фиксированный календарь (МФК) — v1.3

Веб-приложение для перевода дат между **5 календарями** и **МФК** на **8 языках**.

## Поддерживаемые календари

- 🌍 Григорианский
- 🏛 Юлианский
- 🀄 Китайский солнечный (24 сезона 节气 + 60-летний цикл 干支)
- ✡ Еврейский (לוח עברי)
- 📅 МФК (13 × 28 + Високосный день)

## Языки интерфейса (8)

| Флаг | Язык | Код | Направление |
|------|------|-----|-------------|
| 🇷🇺 | Русский | ru | LTR |
| 🇬🇧 | English | en | LTR |
| 🇫🇷 | Français | fr | LTR |
| 🇪🇸 | Español | es | LTR |
| 🇧🇷 | Português | pt | LTR |
| 🇨🇳 | 中文 | zh | LTR |
| 🇮🇱 | עברית | he | **RTL** |
| 🇸🇦 | العربية | ar | **RTL** |

- Выпадающее меню с флагами, названиями и кодами
- Автоопределение по `navigator.language` (включая устаревший код `iw` для иврита)
- **RTL-поддержка**: интерфейс автоматически зеркалится для иврита и арабского

## Возможности

- 38 международных праздников
- Светлая / тёмная тема
- Сохранение настроек в `localStorage`
- Оффлайн-режим (service worker)

## Развёртывание на GitHub Pages

1. Загрузите все файлы в репозиторий.
2. **Settings → Pages → Source → Deploy from a branch**, выберите `main` и `/ (root)`.
3. Откройте `https://<username>.github.io/<repo>/`.

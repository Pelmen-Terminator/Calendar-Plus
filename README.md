# Международный фиксированный календарь (МФК)

Веб-приложение для перевода дат между **григорианским**, **юлианским** и **Международным фиксированным календарём** (International Fixed Calendar, IFC).

## Возможности

- Перевод даты из григорианского или юлианского календаря в МФК и обратно
- Календарь на месяц и на весь год (13 месяцев по 28 дней + Високосный день)
- Отметка международных праздников (Новый год, Пасха, Рождество и др.)
- Переключение темы (светлая/тёмная) и языка (русский/английский)
- Сохранение настроек в `localStorage`
- Работает оффлайн (service worker)

## Структура

- `index.html` — основное приложение
- `manifest.json` — PWA-манифест
- `favicon.svg`, `icon-192.png`, `icon-512.png` — иконки
- `sw.js` — service worker (опционально)

## Развёртывание на GitHub Pages

1. Загрузите все файлы в репозиторий.
2. В настройках репозитория: **Settings → Pages → Source → Deploy from a branch**, выберите `main` и `/ (root)`.
3. Откройте `https://<username>.github.io/<repo>/`.

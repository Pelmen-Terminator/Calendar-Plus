# Международный фиксированный календарь — v1.6

Конвертер дат между 8 календарями на 17 языках. Единый `index.html`, без сборки и сервера.

## Возможности

- 🌍 **8 календарей**: Григорианский, Юлианский, Китайский солнечный, Еврейский, Индуистский, Исламский (Хиджра), Персидский, Коптский
- 🌐 **17 языков**: RU, EN, DE, FR, IT, ES, PT, TR, PL, UK, ID, ZH, JA, KO, HI, HE, AR
- 📅 **42 праздника** (включая Дивали, Холи, Ураза-байрам, Курбан-байрам)
- 📤 **Экспорт в ICS** для Google/Apple Calendar
- 📊 **Разница между датами** (дни, недели, месяцы, годы, по МФК)
- 🔗 **URL-роутинг** — `#/g/2026/10/8`, шарабельные ссылки
- 📋 **Копировать** и **Поделиться** (Web Share API)
- 🌗 Светлая / тёмная тема
- 💾 Сохранение настроек в `localStorage`
- 📴 Оффлайн (service worker)

## Развёртывание

- **Локально**: просто открой `index.html` двойным кликом
- **GitHub Pages**: Settings → Pages → main / root → открой `https://<user>.github.io/<repo>/`

## URL-формат

- `#/g/2026/10/8` — григорианский
- `#/j/2026/10/8` — юлианский
- `#/c/2026/10/1` — китайский
- `#/h/5787/7/1` — еврейский
- `#/i/2083/1/1` — индуистский
- `#/m/1448/1/1` — исламский
- `#/p/1405/7/17` — персидский
- `#/k/1743/1/1` — коптский
